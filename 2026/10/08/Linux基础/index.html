# 二、Linux 命令基础

1、命令行：即 Linux 终端（Terminal），是一种命令提示符页面，以纯 “字符” 的形式操作系统，可以使用各种字符化命令对系统发出操作指令。

2、命令：即 Linux 程序，一个命令就是一个 Linux 的程序。命令没有图形化页面，可以在 Linux 命令行（终端）提供字符化的反馈。
