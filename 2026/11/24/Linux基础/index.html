二、Linux命令基础

1、什么是命令行、命令

1、命令行：即Linux终端（Terminal），是一种命令提示符页面，以纯“字符”的形式操作系统，可以使用各种字符化命令对系统发出操作指令。

2、命令：即Linux程序，一个命令就是一个Linux的程序。命令没有图形化页面，可以在Linux命令行（终端）提供字符化的反馈。

2、Linux命令通用格式

command [-options] [parameter]

  • command 命令本身

  • -options ：[可选、非必填]命令的一些选项，可以通过选项控制命令的行为细节

  • parameter ：[可选、非必填]命令的参数，多数用于命令的指向目标等

eg：

  • ls -l /home/yuyu , ls是命令本身，-l是选项，/home/yuyu是参数

  • 意思是以列表的形式，显示/home/yuyu目录内的内容

  • cp -r test1 test2, cp 是命令本身，-r是选项，test1，test2是参数

  • 意思是复制文件夹test1成为test2

3、ls命令

1、ls [-a -l -h] [Linux 路径]

  • -a -l -h是可选项

  • Linux路径是此命令的可选的参数

当不使用选项和参数是，直接使用ls命令本体，表示：以平铺形式，列出当前工作目录下的内容

  • 当前工作目录可以使用pwd命令查看，打开终端默认加载Home目录，Home目录是Linux系统的个人账户目录

2、ls参数作用

  • -a 选项，表示all的意思，及列出所有文件(包含隐藏文件/文件夹)

    • ” . “开头的即隐藏文件/文件夹

  • 只有通过-a选项，才能看见隐藏文件/文件夹

  • -l 选项，表示：以列表(竖向排列)的形式展示内容，并展示更多信息

  • -h选项，需要和-l搭配使用，以更加人性化方式显示文件的大小单位

4、cd、pwd命令

1、cd [Linux路径]

  • cd命令无需选项，只有参数，表示切换到哪个目录下

  • cd命令直接执行，不写参数，表示回到用户的Home目录下

2、pwd

  • pwd命令，无参数，无选项，直接输入pwd即可

  • 查看当前所在的工作目录

3、路径

  • 绝对路径：以根目录为起点，描述路径的一种写法，路径描述以 “/” 开头

  • 相对路径：以当前目录为起点，描述路径的一种写法，路径描述无需以 “/” 开头

4、特殊路径符

  • . ： 表示当前目录

  • .. ：表示上级目录

  • ~ : 表示Home目录

5、mkdir

mkdir [-p] Linux路径

  • 创建新的目录(文件夹)

  • 参数必填，表示Linux路径，即所创建文件夹的路径，相对、绝对路径均可

  • -p 选项可选，表示自动创建不存在的父目录，适用于创建连续多层级的目录

6、touch、cat、more

1、touch Linux路径

  • 建立文件

  • touch命令无选项，参数必填，表示要创建的文件路径，相对、绝对路径，特殊路径符均可

2、cat

  • cat Linux路径

  • cat同样没有选项，只有必填参数，参数表示：查看的文件路径，相对、绝对路径，特殊路径符均

  • cat查看内容

3、more

  • more Linux路径

  • more同样没有选项，只有必填参数，参数表示：查看的文件路径，相对、绝对路径，特殊路径符均

  • cat直接将全部内容显示出来

  • more支持翻页，内容过多可以一页一页展示

  • 空格翻页，q退出查看

7、cp、mv、rm

1、cp

  • 复制文件或文件夹

  • cp [-r] 参数1 参数2

  • -r可选，用于复制文件夹使用表示递归

  • 参数1：Linux路径，表示被复制的文件或文件夹

  • 参数2：Linux路径，表示要复制去的地方

2、mv

  • mv表示移动的文件或文件夹

  • mv 参数1 参数2

  • 参数1：Linux路径，表示被复移动的文件或文件夹

  • 参数2：Linux路径，表示要移动的去的地方，如果目标不存在则进行改名确保目标存在

3、rm

  • rm用于删除文件或文件夹

  • rm [-r -f] 参数1 参数2 … 参数N

  • -r 用于删除文件夹

  • -f 强制删除

    • 普通用户删除不会弹出提示，root用户删除会有提示

    • 一般用户用不到 -f

  • 参数表示要删除文件或文件夹的路径，用空格隔开

4、rm命令支持通配符 * ，用于模糊匹配

    • 表示通配符，即匹配任意内容(包含空)

  • test*，匹配以test开头的内容

  • *test，匹配以test结尾的内容

  • *test*，匹配任何包含test的内容

8、which、find、grep、wc

1、which

  • which 参看命令的程序文件存放在哪里

  • which 命令

2、find

  • 通过find命令查找指定的文件

  • find 起始路径 -name “被查找的文件名”

  • 支持模糊查询 *

    • test*，匹配以test开头的内容

    • *test，匹配以test结尾的内容

    • *test*，匹配任何包含test的内容

  • find 起始路径 -size +|- n[kMG]

    • +、- ：表示大于和小于
    • n：表示大小数字
    • kMG：表示大小单位，k(小写字母)表示kb，M表示MB，G表示GB

3、grep

  • 从文件中通过关键字过滤文件的行

  • grep [-n] 关键字 文件路径

    • -n 可选，表示在结果中显示匹配的行的行号

    • 关键字，表示过滤的关键字，带有空格或其它特殊符号，建议用 “ “将关键字包围起来

    • 文件路径：表示过滤内容的文件路径， 可作为内容输入端口

4、wc

  • wc命令统计文件的行数、单词数量

  • wc [-c -m -l -w] 文件路径

  • -c ，统计bytes数量

  • -m ，统计字符数量

  • -l ，统计行数

  • -w ，统计单词数量

  • 参数，文件路径，被统计的文件，可作为内容输入端口

9、管道符

  • |

  • 将管道符左边命令的结果，作为右边命令的输入

10、echo、重定向符、tail

1、echo

  • 在命令行内输出指定内容

  • echo 输出内容

  • 无需选项，参数，表示输出内容，复杂内容用 “ ”，包围

  • echo pwd

    • 本意输出当前路径，但是pwd被当作普通字符输出

    • 可以使用反引号 ``将其包围起来，会被当命令执行，而非普通字符

2、重定向符

  • >和>>

  • >,将左侧命令结果，覆盖写入符号右边指定的文件中

  • >>,将左侧命令结果，追加写入符号右边指定的文件中

3、tail

  • 可以查看文件尾部内容，追踪文件的最新更改

  • tail [-f -num] Linux 路径

  • 参数Linux路径，表示被跟踪的文件路径

  • -f，表示持续跟踪

  • -num，表示查看尾部多少行，默认10行

11、vi\vim

vi/vim，Linux系统里面的文本编辑器，vim是加强版的vi

  • vi/vim 文件路径

    • 如果文件不存在，编辑新文件

    • 如果文件存在，编辑已有文件

  • 命令模式

  • 输入模式

  • 底线命令模式

三、用户和权限

1、root用户(超级管理员)

  • root用户拥有最大的操作系统权限，而普通用户在许多地方的权限是受限的。
  • 普通用户的权限，一般在其HOME目录内是不受限的
  • 一旦出了HOME目录，大多数地方，普通用户只有只读和执行权限，无修改权限

2、su命令切换用户

  • su [-] 用户名

    • 符号可选，表示切换用户后加载环境变量，建议带上

  • 参数：用户名，表示要切换的用户，用户名省略，表示切换root用户

  • exit退回上一用户，也可以使用ctrl+d

  • 使用普通用户，切换其他用户需要密码，如切换root用户

  • 使用root用户切换其他用户，无需密码，可以直接切换

3、sudo临时提权

  • 在其它命令之前，带上sudo，即可为这一条命令临时赋予root权限

  • 但不是所有的用户，都有权使用sudo，我们要为普通用户配置sudo认证

  • 为普通用户配置sudo认证

    • 切换root用户，执行visudo，会自动通过vi编辑器打开/etc/sudoers

    • 在文件的最后加上 用户名 ALL=(ALL) NOPASSWD： ALL

      • 其中最后的NOPASSWD:ALL表示使用sudo命令，无需输入密码

    • 最后wq退出

4、用户和用户组

  • 1、Linux系统中可以：

    • 配置多用户

    • 配置多用户组

    • 用户可以加入多个用户组

  • 2、Linux中关于权限的管控级别有2个级别，分别是：

    • 针对用户的权限管控
    • 针对用户组的权限管控

  • 3、创建用户组（以下命令需root用户执行）

    • 创建用户组
    • groupadd 用户组名
    • 删除用户组
    • groupdel 用户组名

  • 4、用户管理

    • 创建用户
    • useradd [-g -d ] 用户名
      • 选项-g：指定用户组，不指定-g，会自动创建同名组并自动加入，指定-g需要组已经存在，如已存在通名组，必须使用-g
      • 选项-d：指定用户HOME路径，不指定，HOME目录默认在：/home/用户名
    • 删除用户
    • userdel [-r] 用户名
      • -r：，删除用户的HOME目录，不使用-r，删除用户时，HOME目录保留
    • 查看用户所属组
    • id [用户名]
      • 参数：用户名，被查看的用户，如果不提供则查看自身
    • 修改用户所属组
    • usermod -aG 用户组 用户名 ，将指定用户加入指定用户组

  • 5、getent

    • getent passwd命令可以查看当前用户有那些用户
      • 显示七分信息：用户名：密码（X）：用户id：组ID：HOME目录：执行终端（默认bash）
    • getent group命令查看有哪些用户组
      • 包含3份信息，组名称:组认证（显示X）：组ID

5、权限

  • 1、认识权限信息

  • 2、权限信息

  • 3、rwx

    • r表示读权限

    • w表示写权限

    • x表示可执行权限

    • r:针对文件可查看文件内容

      • 针对文件夹，可查看文件夹内容，如ls命令

    • w:针对文件可修改此文件

      • 针对文件夹，可以在文件夹内：创建、删除‘、改名等

    • x:针对文件可将文件当作为可执行的程序

      • 针对文件夹，表示可以更改工作目录到此文件夹，即cd进入

  • 4、chmod命令

    • 使用chmod命令，修改文件、文件夹的权限信息
    • 只有文件、文件夹的所属用户和root用户可以修改。
    • chmod [-R] 权限 文件或文件夹
      • 选项：-R，对文件夹内所有内容应用同样的操作
    • eg：
      • chmod u=rwx g=rx o=x hello.txt，将文件的权限修改为：rwxr-x–x
        • u表示用户权限，g表示用户组权限，o表示其他用户权限
